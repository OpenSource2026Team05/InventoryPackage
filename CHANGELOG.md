# Changelog

All notable changes to this package will be documented in this file.

## [0.1.0] - 2026-08-31

### Added

- 8-slot inventory system
- Item registration and removal
- Slot selection
- Equipped-item state tracking
- Default inventory UI
- Item name and description display
- Optional 3D item preview
- Inventory prefab
- Public APIs for integration with external pickup and equipment systems

### Changed

- Removed project-specific player dependencies
- Removed direct HandPivot dependency
- Removed project-specific Input System integration
- Removed audio and puzzle dependencies
